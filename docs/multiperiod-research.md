# 多周期图表与特征实验

## 图表

共享个股弹窗新增5、15、30、60分钟蜡烛图，保留日K和分时。
只读取本地规范化1分钟库，不为不同周期重复下载数据。
上午与下午分别聚合；60分钟终点为10:30、11:30、14:00、15:00。
09:30单独竞价记录归入首根。缺失或非法历史K线排除，最新未收盘K线标记为形成中。
价格使用本地分钟价格口径，不能与前复权日K的绝对价格直接混用。

## 四组配对研究

入口：StockFormer → 多周期特征实验。
POST `/api/stockformer/multiperiod` 接收 `start`、`end`、`max_symbols`；GET读取最近完成结果。
复用数据任务状态和执行槽。已有同步运行时返回409，不隐式并发重扫数据。
研究样本至少100个交易日，开始前另外需要60个交易日预热历史。
固定种子20260907，从训练前已有足够历史的沪深A股抽样，默认50只。
只保留240分钟完整且与同日日K的价格、成交量、成交额核验一致的股票日。

四组：日K OHLCV子集、日K+60分钟、日K+15分钟、日K+两种分钟。
分钟特征：尾段收益、收盘区间位置、日内已实现波动、尾段量比。
只使用同一天内无量纲比值，避免分钟不复权价格与复权日K混算。
时间顺序60%训练、20%验证、20%独立测试；跨分界的收益标签剔除。
预测标签为下一交易日开盘到其后1/3/5/10个交易日开盘的收益。
四组使用相同股票日和标签；标准化及模型只拟合训练集，固定正则，不按测试结果调参。

输出位于 `data/research/multiperiod/<run_id>/`：
- `report.json`：配置、特征版本、股票池、系数、分组指标。
- `predictions.parquet`：各组逐日预测和实现标签。
- `exclusions.json`：未通过分钟质量校验的股票日及原因。

Top5远期均值是研究排序指标，不是可成交净值或严格组合回测。
分钟覆盖偏差、存活偏差和当前复权版本限制仍需注意。
实验不替换生产模型，不修改历史行情，不自动下单。

## 5分钟交易确认

短线AI荐股中心实时结果新增必需的5分钟确认。
需要当天连续3根完整且已收盘K线，最新结束时间距当前不超过6分钟。
最新收盘高于前两根最高价、收盘高于开盘、成交量不低于前两根均量。
缺失、滞后、非交易时段均不通过，不能覆盖弱市和风险闸门。
历史日级荐股不套用今天的分钟确认；单独标记未执行，避免前视信息。
该规则是待验证的执行过滤器，不是保证盈利的预测。
