# L2 日级特征与配对研究

## 当前能力

这是独立的本地研究流程，不修改生产 StockFormer 模型、行情、荐股、缓存或定时同步任务。
它不需要启动第二套服务，也不需要把原始逐笔文件全部解压入库。

数据链路：本地压缩包 → 有界 CSV 批处理 → 量价与时段校验 → 日级 Parquet → 配对预测实验。
现阶段提供命令行入口，尚未在网页增加按钮或自动晋升模型。

## 数据契约

- 输入是已抽样核对的 Wind 风格 SH/SZ CSV，包含行情与逐笔成交文件。
- 原始价格为整数，除以 10000 得到元；成交数量单位为股。日K参照单位必须显式确定：旧试点默认 `--daily-volume-unit lots`（手），当前 Tushare 标准化日K使用 `--daily-volume-unit shares`（股）。不根据量级自动猜测单位；单位进入提取清单和断点签名。
- 本地日K的六位代码和交易所前缀/后缀形式在研究读取边界统一匹配；不将 `000001.SH` 指数匹配为 `000001.SZ` 股票，别名重复参照仍拒绝。
- 原始日K历史可能混存股/手单位，不能给整段历史随意指定同一参数。此时先在隔离研究副本复用日K流水线的单位标准化，再核对成交均价位于原始高低价范围内、与 enriched 的成交量一致，最后由L2逐笔及收盘快照独立校验。不会自动覆盖生产原始日K。
- 部分2025年包有09:26占位行，仅当日期为0、价格/数量/成交及买卖序号全为0、方向及事件标记全空时才剔除，并逐股记录剔除数量；不跳过真实坏成交。CRC或底层读取失败会明确报错，不把截断的文件当完整数据。
- 压缩目录只选取行情、逐笔成交这两类已知CSV成员；其他文档及脚本不执行、不解压，所选CSV仍须通过路径安全检查。
- 原始时间是北京时间 HHMMSSmmm，先补齐到九位再校验。
- SZ 正价成交使用 `0` 事件；零价 `C` 事件单独排除。SH 接受经试点核对的空白/NUL/`0` 成交标记。
- 沪市收盘成交报告可晚于15:00几秒；首版仅接纳至15:00:05，且延迟报告价格必须全部等于收盘快照价，全天量价仍须完全核对。不改写原始时间。
- B/S 仅表示供应商标注方向，不声称已独立重建主动买卖身份，更不能视作机构身份。
- 不读取委托文件，不生成撤单、订单寿命或精确主力持仓成本。
- 股票代码、日期、时间顺序、全天成交OHLC/数量/金额必须与收盘快照及本地不复权日K一致。
- 盘口要求覆盖至少 46/48 个五分钟时段，且有效深度快照比例不低于 95%。这不是逐笔无丢包证明。
- 日级方向特征要求至少 98% 成交额具有 B/S 标签。不能把未知方向当作中性资金。
- 未通过校验的股票日写入拒绝原因，不进入日级特征文件。

供应商完整字段字典及交付时延未确认，因此全部输出仅限研究。

## 首版特征

| 字段 | 含义与单位 |
| --- | --- |
| `l2_trade_count` | 正价成交记录数，不是委托数 |
| `l2_trade_volume` | 成交股数 |
| `l2_trade_amount` | 按成交价格乘股数汇总的成交额，元 |
| `l2_buy_amount_ratio` | 供应商标注B的成交额 / 全部成交额 |
| `l2_net_buy_amount_ratio` | 标注B减标注S成交额 / 全部成交额 |
| `l2_large_trade_amount_ratio` | 单条成交额不少于20万元的占比，不合并为原始大单 |
| `l2_late_net_buy_ratio` | 14:30至收盘的方向差额 / 全天成交额 |
| `l2_late_amount_ratio` | 14:30至收盘成交额 / 全天成交额 |
| `l2_average_trade_amount` | 每条成交平均金额，元 |
| `l2_vwap_close_gap` | 收盘价 / 全天成交均价 - 1 |
| `l2_depth_imbalance_mean` | 每张有效快照的十档买卖量差 / 总量，再取平均 |
| `l2_depth_imbalance_positive_fraction` | 深度失衡为正的有效快照占比 |
| `l2_spread_bps_mean` | 有效双边最优买卖价差 / 中间价，基点 |

深度是**快照等权**而非时间加权；单边封板时价差缺失，不伪造为零。
方向及尾盘统计包含被供应商标注方向的集合竞价成交，不等同于连续竞价主动净流入。
质量覆盖率、来源、文件哈希不参与模型训练。

## 流式提取

在已安装后端依赖的环境执行，下面从仓库根目录运行：

```powershell
python scripts/extract_l2_daily.py --data-dir ./data --source $env:L2_ARCHIVE_DIR --start 2026-01-05 --end 2026-07-31 --max-symbols 12 --archive-tool $env:L2_ARCHIVE_TOOL
```

`L2_ARCHIVE_TOOL` 指向官方 7-Zip 的 `7z`/`7zr`/`7za`/`7zz` 可执行文件，支持目录中嵌套的日期压缩包。
优先使用官方 7-Zip：本地试跑中，bsdtar 多成员提取耗时异常。工具从 https://www.7-zip.org/download.html 获取，不执行数据包内任何程序。
无7-Zip时可使用支持7z的bsdtar，但不要把GNU tar当作同等能力。

- 按日期顺序运行，每个日期分别流式读取所选股票的成交和行情成员，不生成原始CSV。
- 每批最多8192行，可用 `--batch-rows` 调整到1至65536。
- 同时仅有一个解压子进程；`--timeout` 默认600秒，异常或取消会清理子进程。
- 默认12只试点按开始日前20个已有交易日期的成交额，在00/30/60/68代码组内分层选取；不使用未来收益。
- 这不是行业均衡池，也不是全市场验证。可用 `--symbols` 指定事先冻结的股票池，但需自行避免事后挑选偏差。
- `--max-days` 可先限制试跑日期数。相同数据和股票池再次运行会跳过已完成日期。
- 原始文件大小/修改时间、日K哈希、固定股票池、特征版本或输出哈希变化时，不覆盖已有研究结果。
- 不同试点可用 `--research-dir` 隔离提取和实验；两个入口须传相同目录，默认均为 `data/l2_research`。
- 单日失败继续下一日，连续三日失败停止；拒绝原因保留，不会反复盲目请求网络。

输出位于数据目录下：

```text
l2_research/
  universe.json
  extraction_summary.json
  extraction/YYYY-MM-DD.json
  daily/date=YYYY-MM-DD/part.parquet
  experiments/<run-id>/report.json
  experiments/<run-id>/paired_predictions.parquet
```

目录内的日级结果带有 `feature_version`、`quality_status` 和 `available_at`。
后者采用“次自然日00:00可用”的历史研究假设，不代表已经核实供应商能按时交付。
每个日期有互斥锁；若进程被强杀后留下锁，确认没有活跃提取进程后再人工处理，程序不会擅自解除。

## 对照实验

```powershell
python scripts/run_l2_experiment.py --data-dir ./data --history-start 2025-09-01 --train-start 2026-01-05 --validation-start 2026-05-06 --test-start 2026-06-15 --end 2026-07-31 --universe-file ./data/l2_research/universe.json --max-symbols 12 --top-k 3 --run-id pilot-v1
```

未指定股票代码时优先读取提取器冻结的 `universe.json`，也可用 `--universe-file` 指定它。研究输出ID不可覆盖；没有 `--run-id` 时只向标准输出返回结果。

扩至50只时，可给两个命令都增加 `--research-dir ./data/l2_research_50`，并把 `--max-symbols` 改为50。
日K仍只读原 `--data-dir`，股票池、L2日级文件和实验结果使用新目录，原12只结果不覆盖。
默认分层选股会按新的数量重新划分流动性区间，不保证包含原12只；因此两轮数字不能直接归因为样本数量变化。
每轮结论应首先比较该轮相同股票、相同日期和相同有效样本上的两组模型。
预先冻结的股票还必须满足实验的 `--min-history-days` 门槛；训练前历史不足时，不得按测试收益挑替代股。
少量补充股票可以独立提取，实验用 `--extra-research-dir` 读取补充批次，再以 `--universe-file` 指定合格的冻结池。
每批仍要求完整的校验清单和文件哈希；跨批重复股票日会报错，不会静默覆盖或择优取值。

实验A是生产代码的15项可按历史时点计算的量价特征，加相同的线性岭回归算法。
实验B仅增加13项L2特征，样本、标签、费用假设和正则参数与A一致。
**A不是线上完整特征模型**：当前完整模型的一些辅助数据缺少完整历史发布时间契约，因此本轮不混入。

- 信息日t的数据在次交易日09:25决策，标签为次日开盘买入、h个交易日后开盘的价格变化，h为1/3/5/10。
- 使用完整市场日期轴定位进出日期，不把停牌或缺失股票日压缩成连续交易日。
- 训练、验证、测试按日期隔离；标签退出时间跨越下一分界的样本剔除。
- 标准化只在训练集拟合，不在验证、测试期重新计算，不重新调参或重训。
- 两组仅使用共同完整样本，报告覆盖损失、IC/RankIC、误差、方向正确率、Top-K远期收益均值及差值。
- 10bp是每个远期标签固定扣除一次的往返成本代理，不是完整的手续费、滑点或换手模拟。
- Top-K均值包含重叠持有窗口，**不是组合净值、总收益或可交易回测**。
- 现有前复权历史并非逐日留存的复权版本；幸存者偏差、覆盖偏差、交付时延及行情质量限制均列入报告。

只有在更广股票池、多个市场阶段、实际成交约束及持续交付验证后，才考虑是否替换生产模型。
历史提取不会自动产生实时L2数据能力。

## L2消融和市场状态校准

`scripts/run_l2_diagnostics.py` 是独立离线诊断入口，不调用行情接口，不重新解压原始L2，也不修改线上模型。
它读取已有对照实验的配置和预测，沿用原股票池、日期边界、正则参数、标签及成本假设。
在拟合前将分组、校准规则、代码及输入哈希写入新目录的 `plan.json`；结果不允许覆盖旧目录。

- 6组特征：成交活跃度、成交大小、买卖方向、尾盘资金、盘口深度与价差、VWAP偏离。
- 14组模型：原量价基线、全部L2、每组单独加入、每组从全部L2剔除。
- 全部组合固定使用13项L2都完整、且符合可用时点的共同样本；删特征不扩大样本池。
- 市场状态从本地全部沪深股票日K重建，不只用50只研究股，也不调用当天实时市场过滤器。
- 至少20个连续市场交易日有效行情，当前和前一天有成交；至少200只、当日记录覆盖率80%才分类。
- 站上MA20比例低于40%，且上涨占比低于45%或等权日涨跌为负，归为弱市；站上MA20不少于60%且上涨占比不少于55%归为强市；其余为中性。不足覆盖归为未知。
- 量价基线和全部L2分别比较原预测、全局偏差修正、分市场状态偏差修正。
- 修正只拟合已剔除跨界标签的验证期，按日期等权；不足Top-K的日期不参与拟合，少于10日不修正。
- 单状态至少5日才估计偏差，再按 `n/(n+20)` 向全局偏差收缩。未知或低样本状态回退全局，不填造状态。
- 修正后的验证期成绩属于拟合内，不是独立验证；已经看过的测试期标为“重复使用的历史诊断”，不得声称新样本外通过。
- 日期级偏差修正不会改变同一天股票排序或Top-K名单，误差变小不等于选股能力提升。
- 同时保存训练相关性、特征分布漂移、分市场表现、方向多数类参照和剔除过薄截面的敏感性指标。

以下参数使用已完成的50股试点目录；必须从仓库根目录执行，以匹配原清单中的相对路径：

```powershell
python scripts/run_l2_diagnostics.py --data-dir data --research-dir data/l2_research_50 --extra-research-dir data/l2_research_50_supplement --extra-research-dir data/l2_research_50_recovery --reference-dir data/l2_research_50/experiments/pilot50_20260907_v1 --baseline-snapshot data/l2_research_50_qualified/baseline_input_snapshot.json --output-dir data/l2_research_50/experiments/diagnostics-v1
```

只有原始基线预测精确复现、日K和提取清单哈希前后保持一致，才标记为完成。
输出包含 `report.json`、逐样本 `predictions.parquet`、历史市场状态 `market_history.parquet`、
汇总 `metrics.csv`、分市场 `market_state_metrics.csv` 和 `verification.json`。
这些是诊断研究产物，不是自动上线的策略或新的可交易回测。
