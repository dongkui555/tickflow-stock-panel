# 分钟数据覆盖策略

分钟补差按 `股票 + 交易日` 记录在 `data/user_data/minute_coverage_status.json`，状态与真实分钟文件分离保存：

- `complete`：240 根常规分钟，并通过日K价格、成交量、成交额校验。
- `no_trade`：日K成交量和成交额均为 0，视为停牌/无成交，终止重试。
- `pre_listing`：早于该股票首次日K/上市日期，不检查分钟数据。
- `unknown`：仍未通过校验，保留原因和实际分钟数，不用 0 分钟或中性值伪造完整。
- `source_unsupported`：某源对该股票连续两个历史交易日返回空，后续跳过该源。
- `regular_session`：北交所连续竞价 240 根分钟的价格和成交量通过校验，日K成交额仍包含未覆盖的盘后固定价格交易；保留为常规时段研究数据，不参与全天成交额和高置信度盘中确认。
- `regular_session_close_auction`：北交所 240 根连续竞价的开盘、最高、最低和成交量通过校验，但分钟末端收盘价与日K收盘价存在收盘竞价口径差异；不伪造收盘竞价分钟，保留为常规时段研究数据，不参与全天成交额和高置信度盘中确认。

分钟增强模型的研究训练可以接受真实记录不少于 228 根且覆盖率不低于 0.95 的稀疏样本；这不代表缺失分钟被补齐，也不代表该样本适合实时确认。实时荐股只把 `complete`（完整 240 根）作为盘中分钟确认。其他状态可以保留日K模型的研究结果，但会标记为“仅日K模型”，不能成为高置信度开仓信号。

当天空数据只在收盘后、22:00、次日早盘有限重试；历史补差与当天增量仍由同一日期闸门排队，但不会因为一个源永久空返回而无限重试。`92xxxx` 标的直接绕过 StockDB，使用 Promax、TDX 或离线源。
